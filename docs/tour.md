## 第 5 步 · 地图布局（现在就能读）

[`MapLayout.Generate`](../src/Lumio.Sample.Gameplay/Map/MapLayout.cs) 是一个**纯函数**：同一组参数必须生成完全相同的布局。

三件事值得注意：

1. **地板、硬墙、矿脉三种都是体素。** 按世界模型四问——静态、不动、自身没有服务器逻辑 → 体素，不是实体。
2. **矿脉的剩余储量不在格子里。** 格子里只写方块类型；储量挂在一个 ECS 实体上，两半经一条稀疏引用相连。这是「既不动、又有服务器逻辑」唯一正确的拆法，也是最容易做错的一处——不要把业务数据塞进体素载荷。
3. **刻意不用 `System.Random`。** 它的实现跨 .NET 版本可变，会让「两轮同种子同哈希」这条验收在升级 SDK 后莫名其妙地红。这里自带一个定死的 xorshift32。

跑一下看看：

```bash
dotnet test LumioSample.slnx
```

12 个测试覆盖：同种子逐格相同、不同种子确实不同、边界全是硬墙、占比 0 / 100 的边界、种子为 0 不退化（xorshift 的经典陷阱）、参数校验。
